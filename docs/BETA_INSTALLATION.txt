BYE Beta — @BETA_VERSION@

1. Quit any running BYE beta and open the DMG.
2. Drag BYE Beta into Applications.
3. Eject the DMG and open BYE Beta from Applications.

Upgrading from BYE Apple AI Beta: confirm the new BYE Beta works, then remove
the old app from Applications to avoid opening the previous version. Existing
beta data is reused from ~/Library/Application Support/BYEAppleAIBeta.
Removing the old app bundle does not remove that saved data. The original
BYE app remains separate. The installer excludes caches and preferences.

Updates: BYE Beta now updates itself. It checks the BYE website about once a day,
downloads new versions in the background, and installs them when you quit.
Choose BYE Beta > Check for Updates... to check now, or BYE Beta > Settings...
to turn automatic checks or installs off. Updates are verified with BYE's
release signature. The website's host (Cloudflare) sees your public IP address and app version; no
system profile is sent. This is the last version to install by hand.

Requirements: Apple Silicon Mac; macOS 14 or later; internet for PCC/RMP data.
AI summaries are temporarily unavailable while a better solution is evaluated.
No AI model is initialized or prewarmed. Cached summaries are hidden; existing
summary files are retained. Ratings and original student reviews remain available.
Apple Intelligence, Ollama, an account, and an API key are not required.

This is a locally signed early-tester beta, not an Apple-notarized public release.
If macOS blocks opening a copy you received, follow Apple's instructions for
opening a trusted app in System Settings > Privacy & Security. Only approve
the copy you trust; do not disable Gatekeeper globally. Managed Macs may not
permit this approval.
https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac

Testing: search a PCC course/semester, choose available weekdays, open a
professor, sort/filter original reviews, and quit/reopen to test cached results.
Classes must meet only on selected days; fully asynchronous online sections
also qualify. Clear days to include all schedules, including unannounced meetings.
Ratings are professor-wide. Multiple eligible profiles require your choice.

Known limits: the RMP API is unofficial and may change or reject requests.
Review retrieval requires internet; downloaded text may not include every rating.
Windows and Intel distribution are not included in this installer.
