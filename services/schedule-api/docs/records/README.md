# BYE API project records

These records explain what we delivered, why it was built this way, and what a
new contributor needs to know. They are written for the project owner and other
developers, rather than as a transcript or a list of implementation details.

| Read this | When to use it |
| --- | --- |
| [Delivery record — October 19, 2026](2026-10-19-delivery.md) | Understand the work, decisions, validation and remaining scope |
| [Owner and developer handoff](handoff.md) | Take over the project, manage keys, or prepare the next change |
| [Technical documentation index](../README.md) | Find deployment commands, endpoints, security details and test evidence |

The delivery record is a dated account. Update the handoff when the live system
changes; add a new dated record for a later milestone instead of rewriting the
history. Never put real keys, verification codes, passwords or access tokens here.

**Current boundary:** the hosted schedule API and online owner dashboard are
ready. Windows, Mac and the public website have not yet been connected to this
API, and installed apps do not receive replacement keys automatically.
